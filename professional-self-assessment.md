# Professional Self-Assessment
My ePortfolio shows the work I have completed and improved throughout the Computer Science program at SNHU. It includes projects in software design and engineering, algorithms and data structures, and databases. These projects show how much my skills have improved since I first created them.
When the projects were first made, they worked, but they still has areas that could have been improved. Throughout this capstone, I was able to go back, review my older work, and make it better. I improved the structure of my code, cleaned up logic, added better security, improved the database design, and made the project easier to understand and use. 
This ePortfolio also shows how I solve problems. A big part of computer science is not just writing code, but also knowing how to find issues, test changes, fix errors, and explain what was changed. These artifacts show that process.

## Software Design and Engineering
For software design and engineering, I used my Android event-tracking app from CS-360 Mobile Architecture and Programming class. The original app allowed users to create an account, log in, add events, edit events, delete events, and view events on a calendar.
For the enhancement, I improved the way the app was organized. I added a better structure using MVVM, a Repository layer, LiveData, validation, and background database operations. This helped separate the screen logic from the database logic which made the app cleaner and easier to manage.
This enhancement shows my skills in mobile app development, software design, debugging, and organizing code. The app became easier to read, test, and update. It also beacme more professional because the code was not all placed in one area.

## Algorithms and Data Structures
For algorithms and data structures, I used my Python text adventure game from IT-140 Introduction to Scripting. The original game had rooms, movement, items, and a simple way to win or lose.
For the enhancement, I turned it into a more complete text adventure game. I improved the room navigation, command handling, item collection, trials, and battle system. The game uses dictionaries, lists, loops, functions, and conditionals to control what happens while the player move through the castle.
This enhancement shows my ability to use logic and data structures to create a working program. It also shows problem-solving because the game has different system that need to work together such as movement, inventory, combat, and win/loss conditions.

## Databases
For databases, I used the database from my Android event-tracking app. The original database stored users and events, but it needed stronger security and better organization.
For the enhancement shows my skills in SQLite, database design, data security, and performance improvement. The app now does a better job protecting user information and keeping each user's events connected to the correct account.

## Professional Growth
This capstone helped me see how much I have grown as a computer science student. Earlier in the program, I focused more on just getting the code to work. Now, I better understand that good software also needs to be organized, secure, tested, and easy to maintain.
