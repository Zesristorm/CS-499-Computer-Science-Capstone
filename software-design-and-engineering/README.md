# Software Design and Engineering

## Artifact
The artifact selected for this category is my Android event-tracking app from CS-360 Mobile Architecture and Programming

## Original Artifact
The original version of the app allowed users to create an account, log in, add events, edit events, delete events, and view events through a weekly calendar and full calendar. 
[View Original Artifact](original/)

## Enhanced Artifact
The enhanced version improves the structure, maintainability, and user experience of the app. The app was refactored using MVVM architecture, ViewModels, a Repository layer, LiveData, validation, and background database operations.
[View Enhanced Artifact](enhanced/)
