# Enhanced Artifact

This folder contains the enhanced version of the database files from my Android event-tracking app.

The enhanced database improves security, organization, and performance. Passwords are now stored using password hashes and salts instead of plain text. The app also uses single-use recovery codes, user ID foreign keys, improved date and time storage, database indexes, and a migration process for old data.

These changes make the database safer and more reliable. They also help keep each user’s events connected to the correct account and make event searches easier for the app to handle.
