# Original Artifact

This folder contains the original version of the database files from my Android event-tracking app.

The original database supported basic user accounts and event storage. Users could create an account, log in, add events, edit events, delete events, and view events in the app.

The original version worked, but it had several areas that needed improvement. Passwords were stored as plain text, events were connected to usernames instead of user IDs, and dates and times were stored separately. These issues were later improved in the enhanced database version.
